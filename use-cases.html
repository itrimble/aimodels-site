Use cases

What this archive is for, and which machine to use.

Security research and red-team prep

GLM-5.3-Flash or Flash-Next on one M5; abliterated builds when a stock model refuses legitimate defensive questions (malware triage, exploit write-ups for patched CVEs, phishing-awareness samples).

Where: M5 ×1 (Flash-Next IQ4_XS / alesha IQ3_S), M5 ×2 for DeepSeek V4.1 IQ1_M

Keep abliterated models offline and off public endpoints. Authorised targets only.

Local coding agent

Serve Flash-Next IQ4_XS with llama-server and point an OpenAI-compatible coding agent at it. Only 6B params are active per token, so it is the fastest large model here (theoretical ceiling ≈67 tok/s on one M5). Mellum2.1 12B-A2.5B is the small, fast sidecar; Qwen3.8-27B Q4 is the MacBook Pro travel model.

Where: M5 ×1, MacBook Pro

Code never leaves the LAN. Qwen Community License allows internal commercial use.

Private document Q&A

Open WebUI + llama-server + your own documents, with EmbeddingGemma 2 or bge-small building the local index. Long native context (262K on Qwen3.8, 1M advertised on GLM-5.3/DeepSeek V4.1) helps, but KV cache grows with context; start at 32K.

Where: M5 ×1, MacBook Pro

Client documents and embeddings stay on hardware you own.

Local RAG and search

EmbeddingGemma 2 (1.5 GB) or bge-small (0.07 GB) builds a private index; pair it with Flash-Next or Qwen3.8-27B for answers. No text leaves the LAN.

Where: M5 ×1, MacBook Pro

Embeddings and prompts stay local. No third-party embedding API.

Content for Remnant apps

Z-Image Turbo or FLUX.1 schnell for fast concept art, Qwen-Image 2.1 / MOSS-Image for heavier work, SeedVR2 for upscaling, Wan 2.2 or HunyuanVideo for clips, ACE-Step for background music.

Where: M5 ×1 (image/music), M5 with offload (Wan)

Check licenses: Qwen-Image 2.1, the Qwen-Image Q4_K_M GGUF and YuE2 are non-commercial; Z-Image, FLUX.1 schnell, MOSS-Image, Wan 2.2 and ACE-Step are commercial-OK.

Voice: transcripts, narration, voice notes

Whisper turbo for meeting/podcast transcripts; Kokoro 82M or NeuTTS Air for fast lightweight speech; Qwen3-TTS (Apache 2.0) for narration with your own cloned voice; Fish S2 Pro for research comparisons only.

Where: Every machine except the NAS for TTS; Whisper even runs on the Mac mini

Only clone voices with consent.

Vision: screenshot and UI review

All four LLM families are image-text-to-text; load the mmproj file with llama-server to ask about App Store screenshots, error dialogs or diagrams.

Where: M5 ×1, MacBook Pro (27B)

Use the mmproj that ships beside each GGUF.

Quantization lab

Original safetensors are archived so you can make your own GGUFs or try new quant methods (GSQ-RCO, Mirai) without re-downloading 1.2 TB.

Where: Any box with disk; M5 to test results

Originals are the source of truth; keep the archive offline-safe.
