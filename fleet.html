Method

  • memory: Estimated memory = resident weight bytes x 1.05 + 4 GB (runtime + about 32K tokens of KV cache) for LLMs; media = files + 4 GB, an upper bound since ComfyUI/Diffusers offload components. Estimates, not measurements.
  • tok_s: Token/s = memory bandwidth / (active params x bits-per-weight / 8). Bits-per-weight = GGUF bytes x 8 / GGUF parameter count. This is a theoretical ceiling for generation; real numbers are usually well below it. Two-box figures take off 18% for RPC only when the model does not fit one box (otherwise run it on one box). Not given where active params are unknown or the model needs conversion.
  • verdicts: fits = fits in the GPU-usable budget; offload = needs raised limits or CPU/RAM offload; convert = original safetensors, quantize first; after-RAM-upgrade = MoE expert offload once omarchy has 128 GB; unknown = machine specs unknown.

Diffusion and speech models don't split across two boxes, so the M5 ×2 column for them means "on either box". Maya, Mirai and Strata builds use forked engines without llama.cpp RPC, so they get "No" on M5 ×2 unless they already fit one box.
